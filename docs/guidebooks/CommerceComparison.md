# HELIOS — Candidate Comparison Engine

## Evaluation Matrix

`CommerceComparator` evaluates candidates side-by-side using a multi-factor score:

$$\text{Score} = (0.4 \times \text{RatingNorm}) + (0.4 \times \text{MatchRatio}) + (0.2 \times \text{ValueFactor})$$

## Comparison Table Attributes

- Price in INR
- Merchant Platform
- Rating Stars & Review Volume
- Satisfied vs Violated Constraints
- Composite Match Score
