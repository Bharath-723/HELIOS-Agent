# HELIOS — Explainable Recommendation Engine

## Transparent Decision Rationale

`CommerceRecommender` formulates explainable recommendation decisions that articulate:
1. **Selected Candidate**: The optimal candidate matching constraints.
2. **Reason**: Clear natural language explanation of budget fit, ratings, and feature satisfaction.
3. **Alternative Candidate**: Next best choice with pricing comparison.
4. **Trade-offs**: Explicitly noted limitations (e.g. wired connection, lack of backlight).
5. **Confidence Score**: Quantitative measure of recommendation reliability.
