# HELIOS Metrics Definitions

---

### 1. Resource Metrics
* **CPU percent**: Normalized processor load.
* **RAM usage**: Physical memory resident set size (RSS) in MB.
* **Thread count**: Total active processes spawned by the runner.
* **Handle count**: Active OS directory descriptors.

---

### 2. Timing Metrics
* **Routing Latency**: Time in ms taken by CAHRA capability checks and rankings.
* **Total Time**: Total elapsed time from prompt request to output retrieval.
