# HELIOS v2: Plan Explainability Specification

This document details the structured explainability object generated by the `PlanExplainabilityEngine` in HELIOS v2.

---

## 1. Goal
Explainability is a core pillar of HELIOS v2. Every decision made during intent parsing, task decomposition, and execution planning must be traceably explained.

---

## 2. Structure of PlanExplanation
The `PlanExplanation` class provides natural language reasons for every planning decision:
- **why_tasks_exist**: Maps each Task ID to a clear statement explaining how it fulfills the user's intent.
- **why_ordering_exists**: Details why specific tasks must execute sequentially or can run concurrently.
- **why_dependencies_exist**: Maps the dependencies array of each task to its preconditions.
- **why_internet_required**: Explains why internet connectivity was enabled or disabled.
- **why_privacy_required**: Details the privacy classification level based on prompt keywords.
- **why_tools_selected**: Justifies tool selection (e.g. why NotesManager was preferred over standard text replies).
- **why_models_suggested**: Explains model choices based on task complexity, cost, and safety.
