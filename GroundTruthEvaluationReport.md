# HELIOS Ground-Truth Evaluation Report

### 1. Verification Strategy
The ground-truth evaluator compares expected intents, modules, parameter structures, and LOCAL vs CLOUD execution pathways:

* **Pass Criteria**: Exact match of parsed action intent and expected routing decision.
* **Partial Criteria**: Matches intent or routing decision alone.
* **Fail Criteria**: Mismatch on both metrics.
